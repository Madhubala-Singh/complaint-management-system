## 🔐 Authentication

### How It Works
1. **Sign Up:** Create an account with email and password
2. **Login:** Access your account securely
3. **Protected Pages:** Dashboard and complaint registration require login
4. **User Profile:** Your name and avatar appear in the dashboard
5. **Logout:** Securely end your session

### Security Notes
⚠️ **Important:** This is a frontend-only demo using localStorage. For production:
- Implement backend authentication (Node.js, PHP, etc.)
- Use proper password hashing (bcrypt)
- Implement JWT tokens or sessions
- Add HTTPS encryption
- Use a real database (MongoDB, MySQL, etc.)

### Test Accounts
Since this uses localStorage, create your own account:
1. Go to `signup.html`
2. Fill in the form
3. Login with your credentials
